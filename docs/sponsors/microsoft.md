## Challenge

Build a production-minded AI agent that solves a meaningful problem in finance, productivity, healthcare, or another high-impact domain.

## Judging criteria

- Customer understanding
- Measurable usefulness
- Path from prototype to production
- Responsible design
- End-to-end functionality

## How BillboardOS fits (proposed)

- **Measurable usefulness:** hours of sales and billing work removed per week; unsold inventory filled; days-sales-outstanding reduced.
- **Path to production:** adapters per sponsor, idempotent state machine, audit trail, deployment plan (e.g., Azure Static Web Apps for the frontend).
- **Responsible design:** no face data, aggregate counts only; weak credit never treated as fraud; human approval on refunds and outreach.
- Workshop to attend: "System Design for Deployed Agents".
