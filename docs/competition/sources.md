## Original source preservation

Place verified originals under `references/original/` locally (see `references/original/README.md`). The binary source uploads were not committed via the GitHub text-file connector. **Do not silently replace the official source with a paraphrase.** Compare against the current official live site where rules or prizes have changed.

## Attribution standard

In team notes use one of these labels:
- **[Official guide]** directly documented in the uploaded competition guide; provide printed page.
- **[Team idea]** explicitly expressed in written brainstorm or reviewed image.
- **[Proposed]** design invented for the MVP or an optional sponsor integration.
- **[Unverified]** requires sponsor booth/starter pack/API confirmation.
