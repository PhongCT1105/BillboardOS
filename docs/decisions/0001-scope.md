# ADR 0001 — Documentation-first, single-screen MVP

**Date:** 2026-10-24  
**Status:** Proposed for team approval

## Context

The core brainstorm includes multiple cities, hardware audience sensing, dynamic pricing, advertiser research, autonomous negotiation, payments and ad delivery. A two-day hackathon cannot safely implement a large production media network at once.

## Proposed decision

Build one working screen with a camera/sensor estimate, a brief-to-quote pipeline, an atomic exclusive slot hold, verified payment where sponsor setup permits, controlled creative scheduling and an operator dashboard. Show a real agent responding to an exception. Add multi-billboard and agent-to-agent shopping as independent extensions.

## Alternatives considered

1. Multi-city simulation only: broad but less convincing physically.
2. Agent-only marketplace: attractive fintech flow without a tangible screen.
3. Hardware-only smart display: impressive sensing but underuses autonomous finance theme.

## Consequences

Pros: cohesive physical-to-financial live loop, easy to judge, bounded attack surface, graceful sponsor integration. Cons: fewer autonomous commercial activities, less scale, requires careful distinction between demo data and observed data.

## Review trigger

Revisit once the team confirms sponsor credentials, device access, group size and which integration can be demonstrated reliably.
